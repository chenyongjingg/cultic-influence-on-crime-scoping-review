# Cultic influence on crime — PRISMA-ScR scoping review

Reproducibility package for a scoping review of how the literature on cults and
high-control groups relates manipulation mechanisms to criminal and judicial
outcomes, and of how completely it reports what would be needed to compare studies.

**The finding in one paragraph.** On 170 abstracts, offence type and jurisdiction are
reported often (48.8% and 52.4%) and the variables that make studies comparable are
reported rarely: a standardised instrument in 1.2%, a comparison or an explicit
"none" in 3.5%, involvement duration in 4.1%. A paired reading of abstracts against
full texts for the same records shows the instrument figure rising from 0% to 28.6%
and the legal-outcome figure from 16.7% to 66.7%. The deficit is at the reading
interface, not in the scholarship — which is why the contribution is a reporting
standard ([`mrs-ci/`](mrs-ci/)) rather than a research agenda.

## The corpus in numbers

1,154 records retrieved from seven source files → 832 unique after deduplication
(entities decoded, titles merged) → 744 after the year and language limits → 628
screened at title and abstract → 191 included → 170 carrying an abstract, which is
the denominator every percentage in the manuscript uses.

## Reproduce

Requires Python 3.10+, a GPU with ~16 GB for the screening stage, and no API keys.

```bash
pip install -r requirements.txt
bash src/pipeline.sh           # harvest -> compose -> screen -> adjudicate -> measure
                               # -> analyse -> experiments -> selfcheck gate
bash src/pipeline_fulltext.sh  # full-text lift test (resumable, ~25 min)
python tools/get.py ...        # not needed: pipeline writes into ./data
```

`src/pipeline.sh` is idempotent: each stage is skipped when its output exists and is
up to date, so an interrupted run resumes rather than restarts. It closes with
`src/selfcheck.py`, which fails the run if the PRISMA chain does not add up or a
denominator is missing.

## Where the numbers live

| File | Contents |
|---|---|
| `results/analysis.json` | every number the manuscript prints |
| `results/construct_table.csv` | the twelve reporting constructs, n/N |
| `results/screening_table.csv` | one row per screened record: verdicts, spans, rule applied |
| `results/fulltext_lift.json` | the paired abstract / window / full-text comparison |
| `results/exp1_detector_validation.json` | detector precision and recall against a hand read |
| `results/experiments.json`, `e5.json`, `exp3_strata.json`, `exp4_terms.json` | sensitivity analyses |
| `supplements/` | S1 deviations, S2 search, S3 worksheet, S4 extraction, S5 sensitivity, S7 validation read (S6, the 50-record precheck sample, contains third-party abstracts and is regenerated by `src/worksheet.py` rather than redistributed) |

The manuscript (`manuscript/manuscript.md`) contains `{{placeholders}}` and no typed
numbers; `src/fill.py` substitutes from `results/analysis.json` and **fails the build
on any unresolved placeholder**.

## Layout

```
src/            pipeline (harvest2, compose, screen, adjudicate, measure, analyse, ...)
src/dev/        one-off probes, model downloaders, and the abandoned LLM extractor
manuscript/     manuscript source + section files
mrs-ci/         the ten-item reporting set, machine-readable
results/        aggregates and audit tables
supplements/    S1-S7
figures/        Fig 1-5 and Fig S1, PNG + PDF

```

## What is deliberately *not* here

The retrieved corpus (`data/raw/*.jsonl`) and the full texts (`data/fulltext/*.txt`)
are third-party content and are not redistributed. They are reconstructed by running
the search scripts; `results/raw_manifest.json` gives the byte count and SHA-256 of
every raw file the analysis was run on, so a reproduction can be checked against it.

## Status and known limits

- Screening used Qwen2.5-14B-Instruct at 4-bit AWQ. Human adjudication of
  `supplements/S3_author_worksheet.csv` is **outstanding**; the numbers here are the
  machine record.
- Screening precision was measured at 48–68% on a 50-record read, and the detectors
  at precision 0.80 / recall 0.45 on a 29-record read. Every percentage is therefore
  a **lower bound**.
- Full text was obtainable for 24.7% of included records; the subset is biased
  towards open access.
- OpenAlex was unavailable (credit exhaustion) and replaced by a six-source stack;
  see `docs/deviations.md` D-9 and D-13.
